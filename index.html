Methodological Specifications

This dashboard implements the exact mathematical formulations specified in the official Round 1 Methodology Report.

1. Context Baselines:
Deliveries segmented into expectation cells by phase (Powerplay, Middle, Death), bowling type (Pace, Spin), and wickets lost (0-2, 3-5, 6+).

2. Empirical Bayes Shrinkage:
All player rates regularized toward league expectations based on sample size (K = 40 to 60), penalizing small-sample outliers.
3. Reliability Scoring Formula:
PRS = [40% Context Performance + 25% WPA + 20% Situational Delta + 15% Consistency] × Recency Factor (2024-2026 1.5×).

4. Canonical Alignment:
Every single player name is mapped 1:1 against competition_team_player_mapping.csv and the official Unstop selection dropdowns.
